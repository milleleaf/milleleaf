# Real-world Office fixtures

Real files made by real office applications, not generated by us, used to find what Milleleaf loses
on import and export (run.sh steps 17 and 18). Each is byte-identical to the published file
(SHA-256 below). None has been edited. The Word and Excel files are free to publish: each is under
Creative Commons Attribution 4.0 (CC BY 4.0), with the attribution it requires given below. The deck
is still the GOV.UK one, which is not (see its section); an authored deck replaces it.

**How they were found (21 Oct 2026):** Zenodo's API was searched for Word, Excel and PowerPoint files
under CC0 or CC BY 4.0 (about 1,100 decks, 690 documents and 1,200 workbooks), and each file's parts
were read through HTTP range requests to count its features. Downloads were made on the trial box,
each into its own new directory, with the record's JSON (its licence) beside it, and nothing in
them was run. The pictures of about 30 leading candidates were looked at, on the box: almost every
real document and deck carries an institution's or project's logo, a licence button, stock clipart
or screenshots of someone else's site, which the bar excludes. The candidates are listed at the
end of this file; what their round trips found is in the project notes.

**How the counts were made:** with `python3 -I`, `zipfile` and `xml.etree`, and
`tools/inventory/ooxml_inventory.py`. The personal-data scan ran email and phone regexes over the
text and the attribute values of every XML part, and listed comment authors and the document
properties' people.

## Fixtures (`fixtures/`)

Editor re-saves **of Milleleaf's export** of each real file (`tools/inventory/roundtrip.sh`, which
adopts the file and exports it again), and real edits made in the editors. The tests import them
against the adopted file: a re-save must be no change, an edit exactly that edit.

| File | Made by | How |
|---|---|---|
| `paper.libreoffice-resaved.docx` | LibreOffice 24.2.7.2 (Linux, the CI image on the box, `--network none`) | `soffice --headless --convert-to docx:"MS Word 2007 XML"` of `paper.reexport.docx` |
| `lca-model.libreoffice-resaved.xlsx` | LibreOffice 24.2.7.2, the same way | `soffice --headless --convert-to xlsx:"Calc MS Excel 2007 XML"` of `lca-model.reexport.xlsx` |
| `paper.msoffice-resaved.docx` | Word 16 (Mac), by hand | open `paper.reexport.docx`, save as .docx. **Pending** |
| `paper.msoffice-blank-line.docx` | Word 16 (Mac), by hand | open `paper.reexport.docx`, press Enter at the end of paragraph 3, save. **Pending** |
| `lca-model.msoffice-resaved.xlsx` | Excel 16 (Mac), by hand | open `lca-model.reexport.xlsx`, save as .xlsx. **Pending** |
| `lca-model.msoffice-margins.xlsx` | Excel 16 (Mac), by hand | open `lca-model.reexport.xlsx`, on sheet Graphs set the left margin to 1 in and the Standard Width to 12, save. **Pending** |
| `briefing.*` | see the deck's section | |

Until a pending file is there, its part of the test prints `PENDING` and is skipped (run.sh step 18
shows those lines).

## Replaced on 21 Oct 2026

The first set (16 Oct) was three GOV.UK files under the Open Government Licence v3.0: Ofsted's Board
minutes of 7 February 2017 (`board-report.docx`), Homes England's Reference Class Forecasting Workbook
(`finance.xlsx`) and the Ofqual/DfE slide pack above. OGL v3 doesn't cover departmental logos and
crests: the Ofsted logo in the minutes and the Ofqual imagery in the deck aren't licensed by it, so
those files can't go into a public repo. The minutes and the workbook were
replaced by `paper.docx` and `lca-model.xlsx` (with `lcoh-calculator.xlsx` added); the deck stays
until the authored deck covers what its tests check. Their records (sources, hashes, inventories,
rejected candidates) are in git history: this file as of commit bbe3173.
